# Semantic HTML5 Accessible Dashboard

## Project Description

This project is an accessible enterprise dashboard built using semantic HTML5 and CSS.

## Features

- Semantic HTML5 structure
- Accessible navigation
- Header
- Sidebar
- Main content
- Multiple pages
- Data tables
- Accessible forms
- Form validation
- ARIA labels
- Modal dialog
- Responsive design
- Keyboard focus indicators

## Semantic HTML Elements

The project uses:

- header
- nav
- main
- section
- article
- aside
- footer

## Accessibility

The project includes:

- Proper labels for form fields
- Fieldsets and legends
- ARIA labels
- Required form fields
- Email validation
- Minimum length validation
- Table captions
- Table column scopes
- Keyboard focus indicators

## Pages

1. Dashboard
2. Users
3. Reports
